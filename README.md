# 💄 Lunelle Cosmetics

### ✨ Auspify Technologies — Internship Task 01

**Lunelle Cosmetics** is a modern, elegant, and responsive cosmetics website developed as the **first task of my Auspify Technologies Internship**.

The project focuses on creating a visually appealing beauty and cosmetics shopping experience using **HTML, CSS, and JavaScript**, with interactive product filtering, lipstick shade selection, cart functionality, responsive navigation, and a contact form.

## 🖼️ About The Project

Lunelle Cosmetics is designed as a feminine and elegant cosmetics storefront where users can explore different beauty products and interact with the website through a smooth and user-friendly interface.

The website includes:

* 🏠 Home / Hero Section
* 💕 About Section
* 💄 Cosmetics Product Collection
* 🎨 Interactive Lipstick Shade Selector
* 🛍️ Add-to-Cart Counter
* 🔎 Product Category Filtering
* 📱 Responsive Navigation Menu
* ✉️ Contact Form with Validation
* ✨ Cursor Glow Effect
* 🎞️ Smooth Hover & Floating Animations
* 📌 Sticky Navigation Bar
* 📱 Responsive Layout for Different Screen Sizes

---

## ✨ Key Features

### 💋 Interactive Shade Picker

Users can select different lipstick shades from the hero section.

Available shades include:

* 🌹 Rose
* 🧡 Coral
* 🍷 Berry
* 🌸 Bubblegum
* 🍇 Wine

Selecting a shade dynamically changes the lipstick color displayed on the page.

---

### 🛍️ Product Categories

The product section allows users to filter products by category.

**Categories:**

* All
* Lips
* Face
* Eyes
* Nails

Products are dynamically shown or hidden using JavaScript without reloading the page.

---

### 🛒 Add to Cart

Each product includes an **Add to Cart** button.

When a user adds a product:

* Cart count increases
* A notification appears
* The selected product name is displayed in the notification

This provides a simple interactive shopping experience.

---

### 📱 Responsive Navigation

The website includes a responsive navigation menu with:

* Home
* About
* Products
* Contact
* Cart Counter

A mobile menu button is also implemented for smaller screen sizes.

---

### ✉️ Contact Form

The contact section contains:

* Name field
* Email field
* Message field

JavaScript validation checks the required fields and validates the email format before displaying a success message.

> **Note:** This is a frontend contact form. It does not send messages to a backend or email service.
